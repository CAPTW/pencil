Download **Pencil-0.1.0-prototype.3-r4-windows-x64.zip** and
**PROTOTYPE_3_R4_SHA256SUMS.txt**. Previous assets remain historical.

- Capturing from an external editor opens the result even when Pencil is visible in the background.
- Official API model catalogs load once after completed key entry; manual refresh remains.
- Claude adaptive-thinking blocks are excluded from final writing output; unknown/tool and incomplete responses remain rejected.
- Single-line Edit controls without automatic horizontal scrolling reject direct Accept to prevent truncation; use explicit Copy.

**Accept expires at most 30 seconds after capture**, including inference and review time.
Changed/expired targets are refused. Recapture and review, or choose Copy manually.
Unsupported fields are Copy-only only when safe capture is possible; protected/sensitive
fields are never read. There is no automatic retry, copy, or source restoration.

See [r4 installation and API guide](https://github.com/CAPTW/pencil/blob/main/docs/releases/PROTOTYPE_3_R4_INSTALL.md).
Keys remain in Windows Credential Manager; revoking consent and deleting the key are separate actions.

rewrite, exact Accept reread and translation Undo. This is not all-provider qualification.
New package live API/Gemma UI is NOT_RUN; source CI and package integrity are separate.
Google/OpenRouter/xAI live generation, broad editor support, physical IME, Edge,
other GPUs and reproducible builds remain unverified. Timing targets are not guarantees.
The release validation asset binds the fresh package to its source and actual checks.

# Pencil Prototype 3 r2 — API catalog update

## Prototype 3 r2: API model catalog selection

Use **Pencil-0.1.0-prototype.3-r2-windows-x64.zip** and
**PROTOTYPE_3_R2_SHA256SUMS.txt** from the release. Previous ZIPs and their failure
records remain historical downloads. This is an unsigned prerelease.

1. Open Settings → Optional API setup.
2. Select Claude, Google Gemini, OpenRouter or xAI; enter that service's API key.
3. Click **Load model list**, then select **Available models**. Unsupported rows
   stay visible but disabled. Custom endpoints require manual model IDs.
4. Grant permission separately and click **Keep setup for this session**.
5. Capture synthetic text, select translation/rewriting, and choose **Run API
   Deep** only when ready to send it. Review before explicit Accept or Copy.

**Actual API invocation remains NOT_RUN / unverified.** Catalog success does not
prove billing/quota availability, generation permissions, Pencil JSON compatibility,
quality or latency. No real keys or paid calls were used to qualify these presets.
The isolated installed settings trial used synthetic catalog responses with real
save/status/remove IPC; it did not validate the external service. Settings and
catalog UI evidence do not qualify Provider translation/rewrite/Accept.

Keys remain in memory for the app session, not settings files. Loading the list
sends the key to the selected official provider but no document or generation
request. Saving makes no network request. Restarting clears key and consent;
**Remove API key and permission** revokes the saved setup. There is no automatic
inference retry/fallback. OpenRouter requires ZDR routes and disables fallback,
so a listed model can still fail the stricter inference policy. API access/billing
is separate from CLI subscriptions. Google uses its Chat Completions compatibility
API; Claude uses text-only Messages. See PERSONAL_USE.md for bounded lookup limits.

This revision also includes the scoped RichEdit Undo repair and Codex CLI 0.164.0
compatibility pin. Earlier actual-model evidence belongs to its measured binaries;
new r2 actual Gemma UI/Accept/Undo, installed Codex login/Accept, physical IME,
ordinary profiles and other GPUs are not newly qualified. Preserve source text.
The latest r2 validation file reports exact package-specific tests and CI results.

## Historical original Prototype 3 notes

# Pencil 0.1.0 Prototype 3 — Windows x64

Experimental, unsigned prerelease; not whole-product acceptance. Existing
Prototype 1/2 assets remain unchanged. Exact source and hashes are in the ZIP's
MANIFEST.json, BUILD_RECEIPT.json and release VALIDATION.json/SHA256SUMS.txt.

## Changes

- Coalesced changed-range analysis and stale-result rejection during continued
  typing; soft supersession confirms idle before reusing the local model.
- Completed quality refusals can retain the warm Gemma process after idle
  confirmation; permission revocation and deadlines still stop owned work.
- Conservative person/title/negative-promise checks reject some invented roles
  without replacing the pinned Gemma4 12B IT QAT Q4_0 model with a weaker model.
- Owned build-helper teardown and bounded launcher regression tests improved.

## Install and upgrade

Download the Windows executable ZIP and SHA256SUMS.txt (not GitHub's source ZIP).
Verify its SHA-256, extract to an empty folder, and follow START_HERE.md.
Windows x64, PowerShell 7 and WebView2 are required. Install side-by-side into a
new PencilPrototype3 folder; close the earlier version. No automatic settings
migration or overwrite. Uninstall normally preserves settings and dictionary.
Shared AppData deletion through -RemoveUserData is prohibited.

Explicit Prepare-GrammarLocal.ps1 downloads/verifies about 7 GB of model plus
runtime under their upstream terms. This release includes neither model weights
nor llama.cpp runtime. The default CUDA13.4 profile has bounded RTX5070Ti evidence,
not universal GPU/driver support. For unsuitable GPUs, Start-Grammar.ps1
-WithoutLocalModel provides basic rules and optional separately configured,
consent-bound Deep; it is not equivalent Gemma quality or speed. No silent fallback.
Chromium extension IDs are package-specific: use the ID reported by installation,
load the extension in a new profile, pin its icon and explicitly enable document
and field. Do not disable system security to run this unsigned prototype.

## Evidence and remaining limits

CI-qualified source aa5d493 passed Windows run39966608855 after retaining the
first run39963370820 failure and fixing the test observer's WinError32 race.
Build/installation validation for this release is reported separately in
VALIDATION.json; source CI does not qualify real-model UI behavior.

- Latest installed-extension real Gemma translation/rewrite/Accept: NOT_RUN,
  activation blocked before inference. Earlier scoped successful trials do not
  certify this new binary. Start with disposable synthetic documents.
- Earlier startup/cleanup timeout failures: unresolved despite passing reruns.

- Latest prior model evaluation:43 requests,31 changed,5 unchanged,7 refusals.

  English can remain stiff; lexical guards are not general coreference or

- Desktop Accept remains limited to qualified Windows Edit/RichEdit controls;
  Chromium to explicitly opted-in textarea/simple contenteditable ranges.
  Writer/rHWP need separate paired deployment and are not included in this ZIP.
  Arbitrary Word/Excel/PowerPoint/Hancom editors are not generally qualified.

- No signing, auto-update or broad compatibility guarantee. Mission INCOMPLETE;
